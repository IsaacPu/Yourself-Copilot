# 使用与更新

本分支的 `0.2.0` 是隔离实验预览。下文标明“实验预览”的纸页、纸篓和分类历史对应实验分支，尚未替换现用程序或发布为正式更新。预览请使用独立目录和中性测试数据，不与正在使用的程序共用数据目录。

## 第一次使用

从 [Releases](https://github.com/IsaacPu/Yourself-Copilot/releases/latest) 下载 `Yourself-Copilot-windows-x64.zip`，完整解压到有写入权限的文件夹，再运行 `Yourself Copilot.exe`。不要只从压缩包内打开 EXE，也不要把 EXE 单独移走；两个 XAML 文件、`fonts/` 和 `icons/` 都是运行资源。

`0.2.0` 实验预览还依赖同目录的 `illustrations/`，用于纸篓、纸页卷角与投放方向提示；应与程序及其余资源完整保留。构建和打包脚本均包含此目录，不能只复制 EXE 作为预览包。

首次打开是空的任务和图片库。添加任务时可选择今天、明天或其他日期；此前未完成的任务会在今天单列，原计划日期不变。完成的任务默认收起，展开后可恢复。

文字停顿后自动保存，`Ctrl+S` 可立即保存。保存失败时保留当前输入，请检查文件夹写入权限后重试。

任务页与桌面卡片采用上下分区：任务少时自动收紧任务区，让随手记获得更多空间；任务和长记事分别滚动。空间充足时，短任务列表和展开的已完成项优先完整显示；手动缩小任务区也会保留可操作空间。抓住中间的小手柄可调整高度，旁边的分隔线不响应拖动，两个窗口分别记住比例；手柄获得焦点后可用上下方向键微调，双击恢复自动分配。右上角展开按钮仍可打开完整随手记。

## 实验预览：收起一页，再写一页

在工作台打开“随手记”，正文仍用于输入、选字、复制与粘贴。纸面上方的“拖起这一页”抓手负责搬动整张纸；它与任务页中调整高度的小手柄是两个操作入口，卷角图像只作视觉提示。

- 写完想留下：点“收起，换一张”，旧内容进入“收起的纸页”，保存成功后得到空白当前页。
- 暂时不想要：从纸页抓手拖到纸篓松手，或直接点击纸篓。旧纸进入“纸篓”，仍可找回；没有永久删除、自动到期或自动清空。
- 改变主意：点操作后出现的“撤销”取回刚才的纸页。如果空白页上已经写了新内容，新内容会先进入“收起的纸页”，再取回旧纸。

空白页不产生收起或纸篓记录。取消拖动、在纸篓之外松手，以及投放外部文本或文件，不执行换页；拖动中的原文与当前页内容不一致时也不执行换页。保存失败时保留原文，修复目录权限或空间问题后可重试。

“历史记录”先分“随手记”和“任务”。随手记默认打开“收起的纸页”，另有“纸篓”和“自动版本”；选择一页可只读预览原文，点“取回这页”回到随手记继续写。取回使用副本，原记录仍留在历史里；当前非空页会先收好。同文已是当前页时提示无需重复取回。任务历史只读显示已提交的任务及状态，不提供覆盖恢复，也不混入随手记或未提交草稿。

现有隔离检查覆盖保存、撤销、取回、分类历史、构造的拖放事件及隐藏 WPF 渲染；真实鼠标从抓手拖到纸篓的完整过程仍待人工验收，不能据此认定生产使用已验证。

## 桌面与托盘

拖动卡片标题栏移动，四边和四角均可缩放。锁定只限制移动和缩放，仍可编辑内容。图片通过工作台或托盘菜单添加，支持拖放和粘贴；GIF 仅显示首帧。

关闭工作台会收起到托盘。双击托盘图标可重新打开；退出程序请选择托盘菜单“退出 Yourself Copilot”。隐藏桌面内容不会删除任务和图片。

在设置中开启登录自动运行后，Windows 登录时会静默显示卡片，不主动弹出工作台。此选项会登记当前用户的 Windows 启动项；移动程序文件夹后需重新设置。

## 数据与备份

任务、备忘和图片保存于 EXE 同目录，没有云端同步，本地文件未加密。

| 路径 | 内容 |
| --- | --- |
| `workboard.json` | 任务、备忘、草稿、完成记录和卡片设置；实验预览还包含收起的纸页与纸篓记录 |
| `library.json` | 图片列表、位置、大小、锁定和显示状态 |
| `images/` | 已导入图片的本地副本 |
| `*.json.bak` | 上一次有效保存的备份 |
| `history/workboard/` | 自动恢复与任务内容历史快照；实验预览按分类读取 |
| `*-recovery-*.json` | 数据异常时保留的原始文件 |
| `运行日志.txt` | 运行和异常诊断信息 |

随手记的当前内容仍在停止输入约 600 毫秒后自动保存，历史快照单独按以下规则保留：

以下完整句段、任务提交与分类合并规则属于 `0.2.0` 实验预览；不要据此推断 `0.1.4` 已有相同的新行为。

- 一轮编辑开始时保留旧版本，连续输入、少量退格合并，不逐字生成历史。
- 停笔 30 秒后，新增的完整句段才保留为一版；按句末标点、换行及改动量判断，少量改字和未完成的输入继续合并。持续编辑时，每 5 分钟保留一个恢复点。
- 切换页面、离开编辑、关闭窗口或按 `Ctrl+S` 时保留已保存的结果；相同内容不重复生成。
- 清空备忘，或一次删除/替换至少 20 个字符且达到原文 30% 时，另留修改前的版本。

任务草稿和草稿日期只自动保存在当前数据中，不进入历史；已有任务标题在按 Enter、离开输入框或明确保存后提交，输入过程不生成历史。已提交的任务操作在成功保存后记录。历史列表合并旧的草稿差异及短时间内同句的小改字，按分类去重后显示最近 300 个有效版本；自动版本与任务历史凑满后停止解析更旧快照，不会先截取 300 个文件再去重。原始历史文件不会自动删除，单条损坏会跳过并提示。备份时先退出程序，再复制整个程序文件夹。

## 更新版本

1. 从托盘退出程序，备份整个旧文件夹。
2. 将新 ZIP 解压到临时位置，再将其中的程序与资源复制到旧程序目录，按需覆盖同名程序文件。
3. 保留旧目录中的 `workboard.json*`、`library.json*`、`settings.json*`、`images/`、`history/` 和 recovery 文件，再启动程序。

官方 ZIP 不包含个人数据文件，不会用空白任务覆盖你的数据。若改在新文件夹运行，原目录数据不会自动迁入；请先退出，复制上述数据，再从新目录启动。更换路径后重新设置登录自动运行。

## 环境与反馈

需要 Windows 10 / 11 x64、.NET Framework 4.8 或以上及标准 Explorer 桌面。现有稳定版在 Windows、.NET Framework 4.8.1 环境验证；`0.2.0` 的隔离预览不等于正式发布或所有实际交互已验收，也没有穷尽测试所有多屏 DPI、输入法或 Windows 配置。

当前版本未进行数字签名。Release 附有 `SHA256SUMS.txt`，可用 `Get-FileHash .\Yourself-Copilot-windows-x64.zip -Algorithm SHA256` 核对下载完整性。

遇到问题可在 [Issues](https://github.com/IsaacPu/Yourself-Copilot/issues) 提供版本号、Windows 版本和复现步骤。请先检查截图和日志中的个人内容。
