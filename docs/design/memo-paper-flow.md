# 随手记纸页

随手记像桌边的一张纸：先写下，用完投进纸篓，再写下一张。采用暖白、深绿、留白和少量实体反馈。标题、正文、按钮和拖动由原生控件实现，图片只提供纸篓、卷角与方向提示。

## 当前纸页

正文用于输入、选择与复制。纸面右上角填写标题，默认60%不透明度，获得键盘焦点时为完全清晰；留空时历史使用正文开头。标题上限80个UTF-16代码单元，截断时保留完整Unicode代理对。标题单独自动保存，不按输入次数新增历史。

抓手与调整任务/随手记高度的小手柄分开。只有抓手负责搬动整页，正文拖选不发起换页。按住并超过拖动阈值后，真实纸面缩略图半透明跟随鼠标，靠近纸篓时避让目标；单击不会拿起或抖动。

## 投放与取消

拖入纸篓或点击纸篓，先可靠保存当前标题和正文，再换空白页；空白正文不产生旧纸。“存好换新”及显式纸页撤销按钮已移除。

区域外松手、Esc、窗口失活、改变大小、切页、抓手隐藏或失去捕获时取消并复位，不写旧纸记录。投放校验原文和运行期代次，避免过期抓取误操作新纸；外部文件和文本不走整页动作路径。保存失败保留原文、标题和可重试状态。

成功投放后有短暂收拢、纸篓轻晃和柔和纸张声，有旧纸时显示纸团。关闭界面动画时省略运动；音频资源或设备不可用时静默降级，不影响保存。

## 撤销与取回

Ctrl+Z和Ctrl+Y优先交给当前文字编辑器；正文没有对应文字步骤时再操作纸页栈，标题编辑不接管纸页快捷键。任务标题等其他编辑范围不触发纸页撤销。

纸页动作栈保存切换前的实际标题与正文。撤销、重做及取回前保护新写的非空页，失败不推进栈或代次。新成功动作清除重做分支；普通自动保存不增加纸页命令。动作栈仅在当前进程有效，旧纸记录照常落盘，重启后仍可从历史找回。

历史取回使用副本，原记录不删除。纸篓没有永久删除、自动到期或自动清空策略。历史布局与元数据规则见[历史记录](history-archive.md)。

## 资源与验证

运行时必须携带fonts、icons、illustrations和sounds，构建和打包采用资源白名单。插画来源见assets/illustrations/README.txt；声音为原创程序合成，来源和参数见assets/sounds/README.txt。

存储、失败恢复、跨窗口同步、真实控件事件及原生渲染由tests中的memo-paper专项覆盖，发布边界见[发布审查](release-0.2.0.md)。

设计参考：Apple的可逆废纸篓与快速备忘录、Google Keep的归档/回收、ISSEY MIYAKE对材料与留白的表达。只借鉴动作关系和克制表达，没有使用这些品牌的图形素材。
