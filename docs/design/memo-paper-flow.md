# 随手记：纸页与纸篓

## 目标与版本边界

让随手记像桌边的一张纸：随手写，用完能收好或丢进纸篓，立即得到一张空白纸，旧内容仍能找回。

本设计在 `codex/memo-paper-flow` 实验分支开发，`0.2.0` 仅为隔离实验预览；现用程序未被本实验替换。沿用原生 WinForms/WPF、现有暖白与 sage 配色、字体和 logo，不增加 Web 框架。下文记录当前实现与验收边界，不代表已上线或正式发布；实验不部署到真实用户数据目录。

## 方向比较与选择

| 方向 | 主要动作 | 优点 | 取舍 |
| --- | --- | --- | --- |
| 纸页与纸篓（已选） | 收起纸页；抓住专用抓手投进纸篓 | “写完换新”直观，有轻微的实体趣味；与用户提出的玩法一致 | 必须明确收起与丢弃的区别，并保留点击替代入口 |
| 抽屉 | 把纸收入抽屉，再抽出新纸 | 收纳与找回的含义稳定 | “不想要了”的动作表达较弱，增加一个容器隐喻 |
| 折页 | 折起旧页，翻到新页 | 安静、轻巧，适合连续书写 | 折页状态与编辑/拖动边界不容易发现 |

选择第一种。趣味来自少量清晰动作，不依赖复杂拟物、长动画或装饰性控件。日本服装设计的启发落在材料感、留白、人的动作与对象的关系；不复制品牌图形、字标或服装外观。

## 一张纸的操作

- 正文始终用于输入、选择文字、复制与粘贴；从正文拖选不能搬走整张纸。
- 调整任务/随手记高度继续使用现有小手柄；只有手柄可抓取，悬停与拖动显示手掌反馈。
- 完整随手记纸面上方设“拖起这一页”抓手，与高度手柄分开；正文和装饰卷角不发起整页拖动。桌面卡片和任务页的紧凑随手记也有独立抓取入口。
- 纸面右上方的小“收起”入口将当前内容存入“收起的纸页”，成功后创建空白当前页并回到编辑状态。
- 从纸页抓取点拖到纸篓，或点击纸篓按钮，将当前内容存入“纸篓”，成功后换空白页。
- 纸篓的名称与提示明确“可找回”；默认不永久删除、不自动到期，也不提供自动清空策略。
- 当前页为空白或只有空白字符时，收起、纸篓与纸页拖动禁用，不产生空记录。
- 抓手按下后捕获鼠标，超过系统拖动阈值才拿起纸页；单击不会拿起或换页。以当前真实纸面的渲染缩略图跟随鼠标，包含正在编辑的文字，原位置及装饰变淡；跟手层不拦截输入。取消时恢复原位置、透明度、抓手与投放高亮。
- 整页拖动在应用内完成，不调用操作系统的 `DragDrop.DoDragDrop`，避免在纸面上显示文件投放的禁止光标；拖动保持手形入口反馈。正文仍由文本编辑器处理选字，不发起整页拖动。
- 有效纸篓区域高亮；区域外松手、`Esc`、窗口失活、大小变化、切换页面、抓手隐藏或失去鼠标捕获均取消本轮拿起。尚未提交的纸页仍留在当前编辑器，不写入旧纸记录。
- 投放前及保存入口同时校验当前原文和运行期纸页代次，外部文本/文件不能进入这条整页动作路径；重复投放、内容或代次不匹配的旧拿起状态不执行换页。
- 每次成功换页、撤销或重做后推进纸页代次，普通保存或换页失败不推进。即使旧纸被取回后原文再次相同，换页前的拿起状态也会因代次过期而失效。

## 保存、撤销与取回

1. 收起或投放时，先可靠保存旧纸，再将当前页换成空白；保存失败时保留原文与编辑状态，并显示可重试的提示。
2. 成功后显示快捷键提示，移除显式“撤销”按钮，不增加例行确认弹窗。随手记范围内 `Ctrl+Z` / `Ctrl+Y` 优先交给当前正文编辑器的局部文字撤销/重做；无对应文字步骤时再操作所有窗口共用的纸页栈。任务标题等其他编辑范围不被纸页快捷键接管。
3. 收起、纸篓投放及历史取回进入同一个运行期纸页栈；普通自动保存不产生纸页命令，新的成功纸页动作清除此前重做分支，同文取回不产生新命令。每次撤销/重做都保存切换前的实际正文作为反向目标，例如 A 投放后写 B，撤销回 A 后重做回 B；期间写 C 再重做 B，下次撤销可回 C。与预期不同的新内容先归档保护，旧纸记录不删除。操作失败时原文、保护记录集合、代次及动作栈均保持可重试；动作栈只在当前进程有效，纸页记录照常落盘。
4. 从历史点击“取回这页”也遵循先保护当前非空页的规则，成功后回到随手记继续写；取回是复制原文，原历史记录仍保留。与当前内容相同时不重复收起，并提示已经是当前页。
5. 保护当前纸或恢复操作失败时，保留当前原文与旧纸记录；不能以清空编辑器作为失败回退。
6. 自动保存仍负责防丢；收起/纸篓负责纸页生命周期，自动版本不能冒充用户主动收起的纸。

## 历史结构

历史入口首先分为“随手记”和“任务”，不把二者混在同一列表中。

随手记默认打开“收起的纸页”，另分“纸篓”和“自动版本”：前两者以整张纸为单位，显示首行、时间与摘要，并可查看全文、复制取回；自动版本承接编辑恢复需求。纸页记录保存在当前 `workboard.json` 的 `MemoPapers` 中，自动快照不反复复制整份纸页集合。

任务历史只显示已提交的任务、完成状态和已移除任务，保持只读，不提供覆盖恢复；随手记变化、任务草稿及草稿日期不增加已提交任务记录，也不出现在任务预览中。

旧格式历史文件保留，通过读取投影分别呈现内容。自动版本与任务历史按时间降序读取，先进行各自的投影去重，满 300 条有效记录后立即停止解析更旧文件；不是先取 300 个原始文件。自动版本还合并同日两分钟内同一句的小改字和未完成输入，保留新的完整原文；空版隔开两个纸页会话，不跨空版合并。损坏单条跳过并提示，其他记录继续读取。

“收起的纸页”和“纸篓”分别按收起时间显示最近 300 张，两个主动操作产生的独立纸页不按同文合并。所有 300 条限制均为展示上限，不是磁盘清理，不删除源文件。

## 视觉与反馈

按选定概念图与本轮反馈，完整随手记使用大面积纸白、上方居中抓手、右下卷角和纸篓，保持暖白背景与留白；移除纸内“把念头先放在这里”的大提示，将“收起”降为小入口，转成任务与查看旧纸作为次要入口。纸面空间优先留给真正输入的文字。

拖动时真实纸面的缩略图带轻微倾斜与阴影，跟随鼠标而非原地平移几像素。投放必须先保存成功，随后纸页以约 190 毫秒的收拢反馈进入纸篓，纸篓用约 340 毫秒的轻微左右晃动回应；有纸篓记录时使用 `memo-bin-filled.png` 显示纸团状态，原空纸篓素材仍保留。系统关闭界面动画时省略收拢与晃动，不影响保存和换页；本轮未加入音效。失败、取消和区域外松手不播放成功投放反馈。

按钮名称、工具提示、可见焦点和键盘操作承担发现性；动画与手势只增加乐趣，不成为完成任务的前提。

## 资源与交付边界

原生控件负责文字、编辑器、按钮、鼠标捕获、跟手预览和存储；拿起的纸页从真实界面渲染，不以预制整页图片替代编辑器。`illustrations/` 的透明 PNG 提供空纸篓、有纸团的纸篓、卷角装饰和方向提示。素材由 ImageGen 根据用户选定的项目概念图生成，来源说明保留在 `assets/illustrations/README.txt`，未采用 Apple 或服装品牌的图形素材。

构建与打包脚本均复制 `fonts/`、`icons/` 和 `illustrations/`。隔离预览需同时保留 EXE、两个 XAML 和这三个资源目录；只复制 EXE 会缺失资源，不能作为完整视觉预览。用户数据不属于资源，也不应放进预览或发行包。

已有隔离存储、窗口路由事件、分类历史和隐藏 WPF 渲染检查；路由拖放检查直接构造事件。2026-10-24 另在独立演示窗口通过真实鼠标验收：从抓手拖到纸篓后换空白页、区域外松手不换页、撤销完整恢复、正文拖选文字不搬纸，以及取回历史前先保护当前新增文字。核对隔离 JSON 确认旧纸与新增文字仍在、演示任务未被移除。未对生产数据做这些操作。详见 [验证记录](verification-memo-paper-flow.md)。

2026-10-25 的实现改为鼠标捕获与真实纸面跟手预览，上述旧版路由拖放记录保留为当时的历史证据，不当作新路径已通过的依据。本轮结果单独记录在[纸页手感验证](verification-memo-handfeel.md)，继续使用隔离演示数据，没有部署或公开发布。

## 官方参考：事实与设计推论

- [macOS：删除文件与文件夹](https://support.apple.com/guide/mac-help/delete-files-and-folders-on-mac-mchlp1093/mac)：官方支持拖入废纸篓、移出或放回，清空才永久删除。我们的推论：借鉴可逆投放、明确目标与替代操作，不照搬系统级删除行为。
- [Apple：在 Mac 创建快速备忘录](https://support.apple.com/guide/notes/create-a-quick-note-apdf028f7034/mac)：官方提供快速捕捉、专门文件夹，以及续写上一条或新建的选择。我们的推论：始终保留清晰的当前纸，“换新”由明确动作触发。
- [Apple：在 Mac 删除备忘录](https://support.apple.com/guide/notes/delete-a-note-not5585d71a8/mac)：本机备忘录删除后进入最近删除，并有恢复期限。我们的推论：编辑版本和可找回的整张旧纸分开；本产品不照搬其期限。
- [Google Keep：归档与删除](https://support.google.com/keep/answer/6262765?co=GENIE.Platform%3DDesktop&hl=en)：归档与回收站是不同状态，均有返回操作；删除后有恢复期限。我们的推论：区分“写完收好”和“不再需要”，但本产品默认不自动到期。
- [ISSEY MIYAKE：品牌设计概念](https://eu.isseymiyake.com/blogs/isseymiyake-concept)：官方从一块布出发，关注人体、材料与两者之间的留白。我们的推论：让一张纸及人的动作构成体验，以留白和克制的材料表达服务书写，不复制品牌设计。

## 验收标准

- 两个窗口的小高度手柄均呈手掌反馈，拖动不遮挡任务、完成区或正文；手柄以外不能误调高度。
- 收起、有效拖入纸篓、点击纸篓均得到对应旧纸记录和一张空白当前页，正文选字不触发纸页操作。
- 空白、取消、区域外松手、外部数据、重复或过期拖拽均不改变内容、不新增记录。
- 保存失败、保护当前页失败及恢复失败时原文仍在；重试不会生成重复纸页。
- 文字局部撤销/重做优先；跨窗口纸页撤销/重做按实际快照交换，失败不移动命令栈。历史取回在当前页为空/非空两种情况下都可用；新内容先保护，重启后仍可从纸页记录找回。
- 随手记与任务历史各自呈现；三类随手记记录含义清楚，旧历史可读，投影去重发生在 300 条展示上限之前。
- 不删除旧文件，不执行永久删除或自动到期；验证仅使用隔离测试数据，稳定版与实验版不混用用户目录。
- 在常用与最小窗口尺寸检查真实渲染、焦点、键盘、长内容滚动和减少动态效果；分别记录实现、自动验证与实际 UI 验收结果。
