# 纸页手感与撤销重做：实验预览验证

日期：2026-10-25。分支：`codex/memo-paper-flow`。版本继续为 `0.2.0` 实验预览，未部署、未公开发布。

本轮依据用户试用反馈修正跟手拖动、撤销/重做与投放反馈。此前[纸页与纸篓验证](verification-memo-paper-flow.md)保留为旧实现的历史证据，本文件不覆写其结果。

## 实现范围

- 通过专用抓手捕获鼠标，超过拖动阈值后才拿起；使用当前真实纸面的渲染缩略图跟随鼠标，原位置变淡。正文仍为真实可编辑文本，整页拖动不调用系统文件拖放。
- 取消、区域外松手、窗口失活、窗口大小变化、切换页面、抓手隐藏或鼠标捕获丢失时恢复当前纸页；原文或纸页代次失配不能投放。
- 移除显式撤销按钮。`Ctrl+Z` / `Ctrl+Y` 优先处理当前正文编辑器的本地文字步骤，再处理跨窗口共用的运行期纸页栈；不接管任务标题等其他编辑范围。
- 收起、投纸篓及历史取回参与纸页栈。每次成功重放记住离开的实际正文作为反向目标；与预期不同的新内容先归档，失败不移动栈或纸页代次。普通保存不产生纸页步骤，重启不保留快捷键链，落盘旧纸仍在。
- 移除纸内大提示，“收起”变为小入口。成功投放后纸页约 190 毫秒收拢，纸篓约 340 毫秒轻晃；有纸篓记录时使用 `memo-bin-filled.png` 显示纸团。
- 系统减少动态设置下省略收拢和晃动；本轮未接入音效。

## 真实鼠标与键盘检查

根代理在独立原生预览窗口使用演示内容验证，并按步骤观察结果；没有对现用用户数据做这些操作。

- 单击抓手不拿起、不换页。
- 从抓手拖到纸篓以外松手，取消拿起并保持当前原文。
- 从抓手拖入纸篓后，旧纸进入纸篓，当前页变为空白。
- 纸页 `Ctrl+Z` 取回，`Ctrl+Y` 重做，实际窗口与隔离持久化内容一致。
- 在实际正文编辑器末尾追加“测试文字撤销”，`Ctrl+Z` 仅去掉追加文字、不换页；`Ctrl+Y` 恢复追加文字、不投放纸篓。

文字与纸页快捷键均已完成上述真实键盘检查。表中最后一轮窗口和包检查包含开始拖动前转焦的修正，最终预览也已重新编译，并再次用真实鼠标验证有效投放。所有检查仍不能替代各类真实输入法的组合验收。
