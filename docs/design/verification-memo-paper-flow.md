## 真实鼠标检查

使用 `.qa/memo-paper-preview-visual` 中独立编译的原生工作台和中性演示内容；不使用生产互斥入口，不读取或改写生产任务数据。通过 Computer Use 操作实际窗口，逐步观察界面，并读取该隔离目录的 JSON 验证持久化结果。

1. 抓住“拖起这一页”，拖至纸面空处松手：正文不变，旧纸数量保持 2。
2. 从抓手拖至纸篓：正文变空，纸篓新增完整原文，旧纸数量从 2 增至 3，演示任务仍为 1 项。
3. 点击“撤销”：原文完整回到编辑器，纸篓原记录仍在。
4. 在正文第一行拖动：选中文字，不产生整纸拖放或换页。
5. 在正文末尾真实输入新文字，再打开历史的纸篓并点击“取回这页”：旧纸回到编辑器，新增文字所在的当前页先完整存入“收起的纸页”，旧纸数量从 3 增至 4，原纸篓记录仍在。
