# 历史记录

历史分为随手记和任务。随手记默认显示“旧纸页”，将纸篓、以前收起及取回时保护的整页放在同一入口；“编辑记录”用于找回修改前的文字。任务记录只包含已提交的任务及状态，保持只读，不提供覆盖恢复。

## 阅读与查找

日期索引以竖线和圆点连接，每日显示内容摘要和时分。同一分钟默认只显示最新一条，其余可展开或收起；折叠不删除记录。收起正在查看的旧条目时，选中该组最新一条；重新加载时保留仍存在的选中来源。滚动条为细圆角，按像素滚动。

阅读区显示真实可选择文本，支持复制完整原文。任务用实心勾选圆与空心圆区分状态，并提供可访问名称，不在正文中重复方括号标签。历史正文、日期与任务状态均不可编辑。

## 标题

纸页标题与正文分别保存。历史列表右键“修改标题”，留空恢复正文摘要；任务条目没有这一操作。旧纸标题保存在MemoPaper.Title，编辑记录改名保存在主数据MemoHistoryTitles的相对路径索引中，不改原快照或时间。重命名不生成正文历史，失败时回滚元数据并给出可重试提示。

标题和正文一起取回。当前非空页先保护，原历史保留；只有正文和标题均相同时，才提示已经是当前页。

## 记录规则

当前内容自动保存与历史恢复点分别处理。任务草稿、草稿日期和标题输入不产生独立历史；已提交任务变更需主保存成功。随手记使用标点、换行、改动量与间隔判断完整句段，并合并同一轮少量修订和输入中间态。这是本地确定性规则，没有AI语义总结。

旧纸页统一显示最近300张，主动产生的独立纸页不按同文合并。编辑记录与任务历史先按各自内容投影去重，再保留最多300条有效记录；损坏单条跳过并提示。所有限制只影响展示，不执行磁盘清理。空版、跨日、较长间隔及大段删除保留各自恢复边界。

## 实现与检查

- WorkboardStore负责共享保存、恢复点、标题元数据和纸页动作。
- HistoryPanel负责分类投影、取回与改名。
- HistoryArchivePanel负责日期索引、分钟分组及选择。
- HistoryReadingView负责只读文档、图形状态和复制。

检查入口为tests/verify-history-panel.ps1、tests/verify-history-archive.ps1、tests/verify-memo-history.ps1及相应窗口检查。最终验证见[发布审查](release-0.2.0.md)。
